ℹ️ Tentang Aplikasi

Aplikasi ini dibuat sebagai tugas praktik matakuliah Pemrograman Berbasis Website menggunakan Vue.js.


Data yang digunakan adalah data dummy (tidak menggunakan database), cocok untuk simulasi dan pembelajaran.

✅ Fitur Utama
  • Tampilkan & kelola daftar stok bahan ajar
  • Filter & sort data stok
  • Tambah dan edit data stok
  • Buat Delivery Order baru
  • Tracking status pengiriman DO
  • Validasi form input
🛠️ Teknologi
  • Vue.js 2 (via CDN)
  • HTML5 + CSS3
  • JavaScript (ES6)
  • Google Fonts
  • Tanpa framework tambahan
  • Tanpa database / API eksternal
